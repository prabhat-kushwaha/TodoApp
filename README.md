# 📌 To-Do App (SwiftUI)

A beautifully designed **SwiftUI** To-Do app that helps you manage your tasks effectively. With a smooth user interface and support for **Light and Dark themes**, this app ensures an intuitive and productive task management experience on **iOS**.

## 🚀 Features

✅ **SwiftUI** – Smooth animations and clean interface.  
🌙 **Light & Dark Mode** – Seamless theme switching for eye comfort.

## 🛠 Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/prabhat-kushwaha/TodoApp.git
   ```
2. **Open the project in Xcode**
   ```sh
   cd TodoApp
   open ToDoApp.xcodeproj
   ```
3. **Build and run the app**
   - Select an iOS Simulator or connect a device.
   - Press `Cmd + R` to run the app.

## 🎨 Customization
- Change the theme in **Settings**.
- Customize task categories and priorities.
